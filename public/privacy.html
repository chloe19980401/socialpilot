我们处理的数据

我们处理团队登录账号、角色和团队录入或从已连接平台同步的社媒账号、帖子、排期与绩效记录。Google 网站看板读取连接邮箱（用于标识连接）、可选的 GA4 属性和 Search Console 站点，以及所选数据源的用户数、会话、浏览量、参与度、搜索点击、曝光、排名、搜索词、落地页和渠道、地区、设备等统计数据。不请求 Gmail、Google Drive 或修改 GA4 与 Search Console 的权限。

用途、存储与传输

Supabase 提供认证与数据库服务。OAuth 令牌由服务端保存，用于向 Google 请求数据，不发送给浏览器或 Gemini。选定的数据源及最近一次报表可能缓存在当前浏览器。仅当你确认发送并运行「AI SEO 分析」，才将本次报表的汇总和日度指标、搜索词、落地页、同比环比和异常诊断数据发送至 Google Gemini API 生成分析；请求不包含 Google OAuth 令牌或连接邮箱。取消不会影响普通看板使用。

Google 数据使用限制

从 Google API 获取的数据依照 Google API Services User Data Policy 及其 Limited Use 要求处理。我们不出售这些数据，不用于广告定向，也不向数据经纪商提供。

撤销授权与删除

可在 Google 第三方连接管理撤销访问。撤销会停止该授权下后续读取，但不会自动删除本地缓存或服务器连接记录。可在浏览器清除此站点的数据；查询、更正或删除服务器记录请联系下列邮箱，我们会核实身份并按适用要求处理。
